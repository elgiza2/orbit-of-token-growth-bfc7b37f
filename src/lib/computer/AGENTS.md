- Browser tools connect directly from Workers to Browser Use Cloud (primary) or Browserbase (standby) over CDP; never use E2B for browser control or handoff. Why: browser availability must not depend on sandbox keys or credit; retain per-owner/bot profiles and leases.
- Bot browsers connect directly over CDP to Browser Use first, Browserbase as standby (no E2B in the browser path; E2B stays for code/video); provider profiles stay separate under the owner/bot lease. Why: E2B outages must not break browsing, and accounts stay isolated.
